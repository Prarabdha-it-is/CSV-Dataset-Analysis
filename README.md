This project analyzes Netflix dataset using Python, Pandas, and Matplotlib.
It focuses on understanding the distribution of Movies vs TV Shows.

Features
  Load and explore CSV dataset
  Display:
  First 5 rows
  Total rows
  Column names
  Count Movies vs TV Shows
  Visualize data using bar chart

Tech Stack
  Python
  Pandas
  Matplotlib
  (Optional) Streamlit

Project Structure
  CSV FILE PROJECT/
  │── app.py
  │── csvproject.py
  │── netflix_titles.csv
  │── README.md

Output
  Prints dataset info in terminal
  Shows bar graph comparing:
  Movies
  TV Shows

Learning Outcomes
  Working with CSV files using Pandas
  Data cleaning & exploration
  Data visualization basics
  Project structuring

Future Improvements
  Add more visualizations
  Use Streamlit dashboard
  Filter by country, year, genre
